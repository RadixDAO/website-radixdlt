<p id="">As you know from <a id="" href="https://www.radixdlt.com/post/sharing-our-public-network-roadmap/">past blog posts</a>, implementation of the Radix Mainnet (Olympia release) is broken down into four "drops", which are internal milestones. &nbsp;At the end of 2020, <a id="" href="https://www.radixdlt.com/post/rpn-1-development-update-drop-2-complete/">Drop 2 was completed</a> and the development team are excited to be able to show you what they've accomplished.</p><p id="">In the below video, Matthew Hine, Radix DLT’s Head of Product, is joined by developers Alex W, Josh, Theo and Sergiy who show some of the key features of an internal test network following Drop 2 completion.</p><figure id="" class="w-richtext-figure-type-video w-richtext-align-center" style="padding-bottom:33.723653395784545%" data-rt-type="video" data-rt-align="center" data-rt-max-width="" data-rt-max-height="33.723653395784545%" data-rt-dimensions="854:480" data-page-url="https://www.youtube.com/watch?v=6lcwnOZK65A&feature=youtu.be"><div id=""><iframe src="https://www.youtube.com/embed/6lcwnOZK65A" scrolling="no" frameborder="0" allowfullscreen="true"></iframe></div></figure><p id="">In this demonstration, Theo quickly spins up a test network with ten nodes and shows off some of the visualisation tools which developers can use to test and monitor network node status and performance. With the network booted up and running well, other team members then showcase key features. Alex connects an early version of the Radix desktop wallet to quickly send some tokens. </p><p id="">Sergiy gives a sneak-peek into the command line tool we've built to easily manage a network validator, including key generation, adding funds, and registering to the network.</p><p id="">Hopefully, this video gives you some insight into our progress. Check in regularly on our progress toward Drop 3 of 4 on our Olympia mainnet release when we will be opening up our Betanet where you will be able to connect and experiment yourself with a network very similar to mainnet.</p><p id="">Until then remember you can stay right up to date with <a id="" href="https://github.com/radixdlt/docs/tree/master/releases">our progress on GitHub</a> and you can check out our <a id="" href="https://github.com/radixdlt/radixdlt-core/releases/tag/1.0-beta.21">release page for the “Radix core” part of Drop 2</a> as well as an <a id="" href="https://github.com/radixdlt/docs/blob/master/releases/drops.md">overview of our progress on the four RPN-1 drops</a>.</p>
