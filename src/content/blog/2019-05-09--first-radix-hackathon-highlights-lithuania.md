<p id="">A key focus at Radix is ensuring that the platform is<a id="" href="https://docs.radixdlt.com/alpha/learn/platform/buildability"> easy for developers</a> to build upon. As such, for the inaugural internal Hackathon project, James and I decided to build a Command Line Interface (CLI) which can be used to interact with the Radix ledger.</p><h2 id="">What is it?</h2><p id="">We built a CLI which allows users to perform simple functions, such as checking their account balance and making transactions. Design-wise, we focused on creating a tool which follows the <a id="" href="https://www.tldp.org/LDP/GNU-Linux-Tools-Summary/html/c1089.htm">UNIX tools philosophy</a>: create simple input/output programs then use the magic of UNIX pipes (“|”) to “stitch” up multiple programs together. This keeps functionality compact and allows a user to leverage existing, well-known tools. The equivalent in the web world are microservices.</p><h2 id="">How did it go?</h2><figure id="" class="w-richtext-figure-type-image w-richtext-align-center" data-rt-type="image" data-rt-align="center"><div id=""><img id="" alt="" src="/assets/6087c864bd15a77beec632bb_5cb756a5c738b51ac49a9bf2_3tI4gnUWSi6Rf3raNrAvKh_38ZXB9qZVpLQYUhGnMfGBluzA6kCWXv61Dn46mG_CkLzwHjFUbV-x2rJELUC46-60EwwDnhuSjnQ0HplnVv3qcmeUyf_S6txYqsTrf5oMHthmAaa.png" width="auto" height="auto" loading="auto"></div><figcaption id="">[caption id="" align="alignnone" width="696"] James and I presenting the CLI in not-so-sunny Buxton[/caption]</figcaption></figure><p id="">After a couple of hours of Java hacking, some DevOps magic from James and more than a couple of shots of rum, we managed to create a simple tool which could read and write transactions asynchronously on a Radix Ledger.Here’s a simple example showing how to read messages sent to my address:</p><p id="">$ radcli get messages<br>{ “from”: “&lt;address&gt;” “to”: “&lt;myaddress&gt;” “msg”: “Whatsup!” }<br>{ “from”: “&lt;address&gt;” “to”: “&lt;myaddress&gt;” “msg”: “Josh, where are you?!” }<br>{ “from”: “&lt;address&gt;” “to”: “&lt;myaddress&gt;” “msg”: “Yo!” }</p><p id="">Now if I want to search my messages for “Josh”, I can just utilize grep, a ubiquitous existing command line utility which is used to search through data:</p><p id="">$ radcli get messages | grep Josh<br>{ “from”: “&lt;address&gt;” “to”: “&lt;myaddress&gt;” “msg”: “Josh, where are you?!” }</p><p id="">The power of pipes!<strong id="">‍</strong></p><h2 id="">Off-Ledger Smart Contracts‍</h2><p id="">As a final example in the Hackathon we presented how a simple CLI paired with pipes could create quite powerful off-ledger “smart contracts”Here’s an automated payment chain:</p><p id="">$ export SAVINGS_PERCENTAGE=0.10<br>$ export SAVINGS_ADDRESS=&lt;address&gt; $ radcli get transfers | jq --unbuffered -r <br>.amount | awk -v percent="$SAVINGS_PERCENTAGE" '{print "-c \"print " percent " * " <br>$1 "\\""; system("") }' | xargs -L1 python | awk -v tok=’radcli nativetoken’ <br>-v address="$SAVINGS_ADDRESS" '{print "send<br>tokens " $1 " " tok " to " address; system("") }' | xargs -L1 radcli</p><p id="">In the above example, Sophie would like to save 10% of every payment that comes into her day-to-day wallet and creates an automated payment chain which instructs this 10% to be sent to her savings wallet. When Sophie receives a payment £10, £1 (10%) is automatically sent to her savings wallet without any need for further intervention from Sophie.</p><p id="">Finally, here’s a faucet service which transfers 10 XRD to anyone who sends a message to my address:</p><p id="">$ radcli get messages | jq --unbuffered -r .from | grep<br>--line-buffered -v ‘radcli myaddr’ | awk -v tok=’radcli nativetoken’ <br>'{print "send tokens 10 " tok " to " $1; system("") }' | xargs -L1 radcli</p><p id="">By keeping the CLI simple and useable with pipes, more sophisticated functionality becomes possible without any extra work, almost like magic!</p><p id="">But most importantly, we were both delighted to be awarded first place by our colleagues for our work!</p><p id="">‍<strong id=""><em id="">Note: As the CLI is built to interact with the internal betanet, we will open-source it only after the public betanet is live. </em></strong></p><p id=""><strong id=""><em id="">‍</em></strong>Have questions?
