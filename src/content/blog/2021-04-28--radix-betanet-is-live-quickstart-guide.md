<p id=""><strong id=""><em id="">This blog article refers to the Olympia Betanet that operated in early 2021. It is not relevant to the Babylon Betanet that is operating in early 2023. For more details on the Radix Roadmap, see </em></strong><a id="" href="https://learn.radixdlt.com/article/what-is-the-radix-roadmap"><strong id=""><em id="">What is the Radix roadmap?</em></strong></a></p><p id="">The Radix Olympia Betanet is now live. Welcome!</p><p id="">Before we get into the fun, it’s worth repeating a little background on what Betanet <em id="">is</em> and <em id="">isn’t</em>:</p><p id=""><strong id="">Betanet is a temporary test network</strong>, pure and simple. It is intended to provide a final, large-scale stress test of the protocol that will be offered to our community as the basis of the first version of the Radix public network (called Olympia).</p><p id=""><strong id="">Betanet is not the beginning of the official public Radix ledger or the official XRD token</strong> – that’s the Olympia mainnet. Unlike mainnet, the Radix team will have ultimate control of the betanet network, and we will be shutting it down shortly before the release of Olympia mainnet. That means that all assets stored on betanet will vanish. In other words, all tokens and transactions on betanet are just playing with “funny money” and nothing will be carried over to the main network (where everything will be forever immutable).</p><p id="">So basically betanet gives us a couple of months of real-world network operation and bug smashing – and gives our community the chance to get familiar with all of the ways that you will be able to participate on the mainnet to come.</p><h2 id=""><strong id="">How do I get started?</strong></h2><p id="">We’ve got first versions of four betanet widgets for the community to play with.</p><h3 id=""><strong id="">Betanet Radix Desktop Wallet</strong></h3><p id="">We’ve got a betanet version of the Radix Desktop Wallet for you to try. You’ll be able to create accounts, get free betanet test tokens, send them to your friends, and generally have a grand old time. A little later in betanet, we’ll even be enabling staking in the wallet so you can see what it will be like to delegate stake to validator nodes. Attaching messages and connecting a hardware wallet are also coming, so stay tuned.</p><p id="">Visit <a id="" href="https://betanet-wallet.radixdlt.com">betanet-wallet.radixdlt.com</a> to download the betanet wallet – or <a id="" href="https://learn.radixdlt.com/article/betanet-desktop-wallet-introduction">click here to view the wallet user’s guide</a>.</p><h3 id=""><strong id="">Betanet Radix Explorer</strong></h3><p id="">Head over to <a id="" href="https://betanet-explorer.radixdlt.com">betanet-explorer.radixdlt.com</a> where you’ll be able to look up information on individual addresses and transactions. A little later in betanet, you’ll be able to view the current betanet tester validator set (which we expect to fill out as our community testers come online).</p><p id="">For a little more detail about using the betanet explorer, <a id="" href="https://learn.radixdlt.com/article/how-to-use-the-betanet-radix-explorer">click here</a>.</p><h3 id=""><strong id="">Betanet Radix Node</strong></h3><p id="">This one’s for the more hard core. If you want to get a feel for participating in Radix network infrastructure, you can run the latest version of the betanet Radix Node. We’ve already selected our <a id="" href="https://www.radixdlt.com/post/betanet-validators-selected">closed group of validator node testers</a>, but you can still run and connect a node to the network as a full node (90% of the experience of running a validator node) or archive node (create your own Radix API endpoint).</p><p id="">If you’ve got some experience with server systems administration or cloud infrastructure, dive into an early form of the Radix Node documentation at <a id="" href="https://docs.radixdlt.com">docs.radixdlt.com</a>.&nbsp;</p><h3 id=""><strong id="">Betanet Radix Node API</strong></h3><p id="">Also for the technically inclined, the Radix Node API provides a way to programmatically get basic information about on-ledger stuff, and control accounts and tokens. The betanet wallet connects to the API endpoint Radix is providing, and developers can also use this to get a feel for what an integration of a wallet, exchange, explorer, or other client might look like, using our JSON-RPC interface.</p><p id="">Click here for our preliminary Node API documentation at <a id="" href="http://docs.radixdlt.com/documentation-component/betanet/index.html">docs.radixdlt.com</a>.<br></p><h2 id=""><strong id="">I want more, more I say!</strong></h2><p id="">You are truly an insatiable tester!</p><p id="">For more information, our <a id="" href="https://learn.radixdlt.com/article/betanet-user-guide-introduction">betanet FAQ</a> (on our shiny new website!) is a great place to start.</p><p id="">And certainly you should join the conversation on the <a id="" href="https://discord.com/invite/WkB2USt">Radix Discord</a>. We’ve created a <em id="">#betanet-discussion</em> channel for like-minded testers like yourself, and the <em id="">#bug-reports</em> channel is absolutely where you should go if your testing turns up any issues of concern. We can’t promise we’ll directly answer every question and report, but rest assured our dev team will be monitoring these chats.</p><p id="">We’ll see you there!</p><p id=""><br></p><p id=""><br></p>
