<p id="">The Radix ecosystem is full of talented developers who are always finding new ways to make the ecosystem more user-friendly and engaging.&nbsp;</p><p id="">As part of the Scrypto Developer Incentives Program, RDX Works recognizes three outstanding contributors to the ecosystem as the winners of the “Impress the CTO” prize.&nbsp;</p><p id="">Each person will be awarded $1500 in XRD for contributing to the Radix ecosystem and developing new and valuable tools.</p><p id="">Rewards are attributed to:</p><ul id=""><li id="">Radix Billboard</li><li id="">Marco Michelino | StakingCoins</li><li id="">HODL6666&nbsp;<br>‍</li></ul><h2 id="">"Radix Billboard" for their Transaction Manifest Builder</h2><p id=""><strong id="">Radix Billboard </strong>will receive an award for creating an outstanding <a id="" href="https://instruct-stokenet.radixbillboard.com/">Transaction Manifest builder tool</a> that allows users to easily and flexibly create custom instructions to be submitted to the network. Not only does it support relevant manifest instructions, it also supports arbitrary Scrypto blueprint schemas.&nbsp;</p><p id="">This means that developers can easily instantiate blueprints from existing packages deployed to the network. It provides blueprint names, arguments, and types of these existing packages, further improving the developer experience on Radix.</p><p id="">The tool shows a deep understanding of manifest resource movement semantics, allowing clever ways to support buckets and proofs. Check its repository in <a id="" href="https://github.com/radixbillboard">Github</a>.&nbsp;<br><br>Radix Billboard had this to say:</p><blockquote id="">Radix's Transaction Manifest is its standout feature, offering unparalleled safety and the ability to compose complex transactions efficiently, something that's notably more cumbersome on platforms like Ethereum. Despite their power, writing these manifests can be challenging and time-consuming, slowing down prototyping and testing.</blockquote><blockquote id="">That's why we created "Instruct", a visual builder tailored for Radix transaction manifests. Instruct simplifies the process, offering developers and power users the ability to quickly and efficiently create transaction manifests with features like auto-completion and validation. Our goal with Instruct is to streamline the development process, helping to accelerate innovation and contribute to the growth of the Radix ecosystem.”</blockquote><h2 id="">"Michelino" for their Transaction Manifest Builder</h2><p id=""><strong id="">Marco Michelino | StakingCoins</strong> has created another <a id="" href="https://tmbuilder.stakingcoins.eu/">Transaction Manifest Builder tool</a>. This tool stands out for its nice UI/UX, offering predefined Transaction Manifests and operating efficiently on mainnet.&nbsp;</p><p id="">It features a variety of functionalities, including adding and withdrawing liquidity from Ociswap, depositing and retrieving LSUs from CaviarNine, redeeming WEFT, and facilitating swaps on Ociswap, DefiPlaza, AlphaDex, and RadixPlanet. It is important to note that this tool is intended for educational purposes and should be used with caution. Check the project’s repository in <a id="" href="https://github.com/nemster/tmbuilder">Github</a>.&nbsp;</p><p id="">Acknowledging his valuable contribution <strong id="">Marco Michelino | StakingCoins</strong> is being awarded $1,500 in XRD.</p><blockquote id=""><em id="">Despite having developed various code in the past, I had never tried my hand at DLT development before. Developing on Radix was easy, fast, and fun.</em></blockquote><h2 id="">"HODL6666" for their Radix Desktop Tool</h2><p id=""><a id="" href="https://x.com/HODL6666?s=20">@hodl6666</a> on X, also known as atlantis-l on Github, has developed the <a id="" href="https://github.com/atlantis-l/Radix-Desktop-Tool">Radix Desktop Tool</a>, an innovative and user-friendly platform for interacting with the Radix network.&nbsp;</p><p id="">The Radix Desktop Tool includes multiple functionalities, such as multiple-to-multiple token transfers, single-to-multiple token transfers, multiple-to-single token transfers, manifest execution, package deployment, token creation, account generation, asset checking, history reviewing, entity verification, format conversion, address QR code generation, and XRD faucet in Stokenet.&nbsp;</p><p id="">The Radix Desktop Tool has a well implemented user interface and user experience, making it straightforward and efficient to use. It includes an easy installation process across MacOS, Linux, and Windows platforms. It’s important to note that the tool requires knowledge of a private key and hence should only be used on Stokenet, with throwaway keys generated using its Account Generate feature, which provides an address that can be verified on the <a id="" href="https://stokenet-dashboard.radixdlt.com/">Stokenet Dashboard</a>.&nbsp;</p><p id="">In recognition of his contribution and the tool’s alignment with the <a id="" href="https://www.radixdlt.com/blog/scrypto-developer-program-incentives">Developer Incentive Program</a>, <strong id="">@hodl6666</strong> is awarded the $1,500 XRD prize.</p><h2 id="">Get Involved</h2><p id="">Teams are encouraged to submit updates through the <a id="" href="https://forms.clickup.com/2689359/f/2j2af-16328/DMP7778WV2SH36JMPI">Ecosystem Success Form</a> to keep the RDX Works team informed of their progress.</p><p id="">If this post has inspired you to contribute your ideas, blueprints, and tools to the community, please sign up for the Radix <a id="" href="https://developers.radixdlt.com/devprogram">Developer Program</a>. Let’s create a tide that lifts all boats within the Radix ecosystem!</p>
