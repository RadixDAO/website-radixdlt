<h1 id=""><strong id="">Olympia Is Here</strong></h1><p id="">The initial release of the Radix Public Network is live! Olympia brings with it the native RADIX (XRD) token and the foundational Radix technology stack, on which the future of both Radix and Decentralized Finance (DeFi) will be built.&nbsp;&nbsp;<br></p><p id="">The Olympia launch is a hugely important milestone for Radix. As the first public release of the Radix Network, Olympia marks the start of a roadmap of releases that will culminate in the unprecedented DeFi readiness and limitless linear scalability of Xi’an. So, what exactly is Olympia?</p><h2 id=""><strong id="">What Is Included in the Olympia Release?&nbsp;</strong></h2><p id="">Olympia has delivered the core of the Radix ecosystem, which will remain in place as Radix continues to grow with future releases. This enables the team to carefully refine essential features in preparation for the launch of more complex development tools in Alexandria and Babylon.&nbsp;<br></p><p id="">With a focus on tokens, Olympia provides all of the necessary functionality to create, transfer, and stake tokens on the network. This includes an unsharded version of the Cerberus consensus algorithm, featuring a minimum throughput of 50 transactions per second (3.5x that of Ethereum). This is more than sufficient to support expected demand as additional features and throughput are added in future releases. These will culminate in the release of Xi’an, which will implement the unlimited linear scalability of fully sharded Cerberus.&nbsp;&nbsp;&nbsp;<br></p><p id="">Here are all of the components included in Olympia:&nbsp;<br></p><ul id=""><li id=""><strong id="">Radix Node software (</strong><a id="" href="https://docs.radixdlt.com/main/node/introduction.html"><strong id="">Learn More</strong></a><strong id="">)</strong><a id="" href="https://docs.radixdlt.com/main/node/introduction.html"><strong id="">&nbsp;<br>‍</strong></a>Implements the core Radix protocol, including Radix Engine v1 and unsharded Cerberus consensus. This can be installed by anyone in order to operate a node on the network.<br></li></ul><ul id=""><li id=""><strong id="">The Radix Engine: (</strong><a id="" href="https://www.radixdlt.com/post/radix-engine-a-simple-secure-smart-contract-alternative"><strong id="">Learn More</strong></a><strong id="">)<br>‍</strong>The first version of Radix’s replacement for the Ethereum Virtual Machine. The Radix engine is a highly efficient, high-security execution environment that will eventually run full DeFi applications following the Babylon release of the Radix Public Network. The Radix Engine v1 allows us to test the security and reliability of the environment before we start adding more complexity to the system.<br></li></ul><ul id=""><li id=""><strong id="">RADIX (XRD) token: (</strong><a id="" href="/assets/6088147cbbc08674b4975349_Economic-2020-V10.4.pdf"><strong id="">Learn More</strong></a><strong id="">)<br>‍</strong>The genesis of the native RADIX token. XRD can be staked to support network security and earn emissions rewards. It is also used to pay transaction fees on the network. eXRD will continue to exist as a permanent bridge to the Ethereum DeFi ecosystem. Holders will be able to convert between eXRD and XRD at any time on a 1:1 basis.<br></li></ul><ul id=""><li id=""><strong id="">Simple Token Creation (Learn More)<br>‍</strong>Radix Engine v1 allows for new tokens to be created, named, minted, burned, and transacted via the JSON-RPC Radix Node API. Like the ERC20 token, these can be created to represent anything the issuer would like on the Radix Public Network. Note, this requires some technical knowledge of JSON and APIs to use. See <a id="" href="https://docs.radixdlt.com/main/node-api/creating-a-token.html">this page on our technical docs site</a> for more information.<br></li></ul><ul id=""><li id=""><strong id="">Radix Wallet (</strong><a id="" href="http://wallet.radixdlt.com"><strong id="">Learn More</strong></a><strong id="">)<br>‍</strong>An initial release of the native Radix Wallet application, featuring easy in-wallet delegated staking. The Radix Wallet is compatible with any token issued on the Radix network and is available for Windows, MacOS, and Linux. Ledger Nano S integration will also be provided.&nbsp;You can find details on how to install the <a id="" href="https://docs.radixdlt.com/main/user-applications/ledger-app-sideload.html">Radix Ledger App here</a>.<br></li></ul><ul id=""><li id=""><strong id="">Radix Explorer (</strong><a id="" href="http://explorer.radixdlt.com"><strong id="">Learn More</strong></a><strong id="">)<br>‍</strong>A website allowing anyone to explore the state of the ledger, including transactions, wallet balances, and a list of active validator nodes that are eligible to have XRD staked to them.<br></li></ul><ul id=""><li id=""><strong id="">Instapass (</strong><a id="" href="https://www.instapass.io/"><strong id="">Learn More</strong></a><strong id="">)<br>‍</strong>Radix’s <a id="" href="https://www.radixdlt.com/post/single-sign-on-compliance-for-the-future-of-defi">unique, single sign-on approach</a> to optional KYC/AML compliance for DeFi. The first version of Instapass supports Radix services such as Instabridge.&nbsp; In future releases, it will allow any developer building on the Radix network to offer both compliant and permissionless financial services.</li></ul><ul id=""><li id=""><strong id="">Instabridge (</strong><a id="" href="https://www.instabridge.io/"><strong id="">Learn More</strong></a><strong id="">)<br>‍</strong>Launching August 5th, Instabridge is an easy-to-use token bridge connecting Radix and other networks, starting with Ethereum. Initially, it will allow for eXRD holders to swap their eXRD 1:1 for XRD. Other tokens and networks will be added in the future.&nbsp;</li></ul><p id="">‍<br></p><p id="">For a more detailed explanation of what the Olympia release includes and what it means for the Radix community, read the <a id="" href="https://www.radixdlt.com/post/radix-olympia-mainnet-is-coming">pre-launch Olympia article here</a>.&nbsp;</p><p id="">‍</p><h2 id=""><strong id="">What Comes Next?</strong></h2><p id="">With Olympia in place to build upon, the Radix team is now focused on delivering the next releases on the Radix roadmap.&nbsp;<br></p><p id="">The first of these will be Alexandria. Alexandria will provide early access for developers to an off-ledger development environment featuring <a id="" href="https://www.radixdlt.com/post/what-is-the-radix-engine-v2">Radix Engine v2</a> and Scrypto — a new, DeFi-specific programming language developed by the Radix team. This will allow developers to begin working on the decentralized applications (dApps) that will be the first to be deployed to the Radix Network when Babylon is released.&nbsp;<br></p><p id="">Babylon will follow Alexandria, making the Radix Engine v2 and Scrypto available on the Radix Public Network. It will also feature the release of the Radix Blueprint Catalog, creating a marketplace for high-quality, modular code. Developers will be able to upload component blueprints and instantiate them as needed to quickly build robust dApps on the network. A licensing system will also let developers specify a recurring, on-ledger royalty each time their code is used in a transaction.&nbsp;<br></p><p id="">Finally, Xi’an will deliver the true limitless power of Radix by implementing the fully sharded version of the Cerberus consensus algorithm. This will provide the practically infinite linear scalability needed for Radix to process all the transaction needs of the global financial market and beyond, all without breaking atomic composability.&nbsp;<br></p><p id="">To see the full roadmap&nbsp; go to <a id="" href="https://www.radixdlt.com/#roadmap">https://www.radixdlt.com/#roadmap</a><br><strong id=""><em id="">‍</em></strong></p><p id=""><strong id=""><em id="">To stay up to date or learn more about Radix, please follow the links below.</em></strong><br></p><p id=""><strong id="">Telegram:</strong> <a id="" href="http://go.radixdlt.com/RadixTelegram">go.radixdlt.com/RadixTelegram</a></p><p id=""><strong id="">Discord:</strong> <a id="" href="http://go.radixdlt.com/RadixDiscord">go.radixdlt.com/RadixDiscord</a></p><p id=""><strong id="">Twitter:</strong><a id="" href="http://go.radixdlt.com/RadixTwitter">go.radixdlt.com/RadixTwitter</a></p>
