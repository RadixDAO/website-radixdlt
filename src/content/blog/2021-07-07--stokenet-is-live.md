<p id="">After over two months of thorough testing, the <a id="" href="https://www.radixdlt.com/post/radix-olympia-betanet-faq">Olympia Betanet</a> was officially shut on July 6th, and we brought our long-term public test network, Stokenet, online. Connection details for node runners will be sent out next week, but here’s a quick FAQ about how Stokenet and our networks will behave.</p><p id=""><strong id="">What is Stokenet?</strong><br>Stokenet will be the main public test network for Radix going forward, free for all to use, where testers and developers can acquire free (test) XRD from a faucet.</p><p id=""><strong id="">Why that name?<br></strong>The name references Stoke-on-Trent in England, the birthplace of Radix!</p><p id=""><strong id="">Who will run validator and archive nodes on Stokenet?<br></strong>Similar to betanet, Radix will provide a geographically distributed set of validators and archive nodes.&nbsp; Community node runners wishing to practice running a validator node on Stokenet are welcome to join the official <a id="" href="https://discord.gg/wpphQJxSmZ">Radix Discord</a> and ask for stake.&nbsp; Please note that stake on Stokenet is not guaranteed, and we may meddle with it while testing out various network conditions.</p><p id=""><strong id="">How often will Stokenet ledger history be reset?<br></strong>Up until the <a id="" href="https://www.radixdlt.com/post/radix-olympia-mainnet-is-coming">Radix Olympia mainnet</a> release, we may clear the Stokenet ledger history periodically, on no set schedule.&nbsp; After the Olympia release, we do not intend to ever reset the Stokenet ledger history.</p><p id=""><strong id="">Will I be able to target my same mainnet Desktop Wallet against Stokenet?<br></strong>Not at first.&nbsp; While this feature is something that we’re interested in implementing, at launch you can expect that a single wallet executable will target a single network, and those interested in using a wallet to interact with Stokenet will need to get a separate binary from our Github releases page.</p><p id=""><strong id="">Are Stokenet addresses different from mainnet addresses?<br></strong>Yes.&nbsp; Every Radix network has a different human-readable prefix for all addresses and IDs, and each network will reject non-matching addresses.&nbsp; In other words, there is no chance of accidentally sending your mainnet tokens to any testnet address or sending testnet tokens to a mainnet address.</p><p id=""><strong id="">Will there be other public test networks?<br></strong>Yes, though they may be shorter-lived and behave under different rules.&nbsp; For now, Stokenet is the only test network intended for public use.</p><p id=""><br></p>
