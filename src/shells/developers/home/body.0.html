ScRypto & Radix Engine

A Radically Better Developer Experience

Smart contract code should be the easy part of your dApp.

Security Through Simplicity

Radix transforms asset management by making tokens, NFTs, and more first-class types in the platform.

Letting you concentrate on crafting powerful dApp logic without the hassle of custom asset behaviors or error-checking.

Powerfully Familiar

Based on Rust, Scrypto is providing the powerful and expressive logic of one of the best-loved languages today, while adding asset-oriented primitives and functions that let the developer focus on quickly programming finance, not programming a blockchain.

Rewarding Innovation

Blueprints are how Radix smart contracts start life. They are reusable pieces of functionality that allow developers to contribute and leverage code that isn’t just open – it’s alive and proven out every day. Combined with the built in on-ledger Developer Royalties system, developers can rely on receiving rewards on network level.

An authentication system which utilizes the Radix Network to provide passwordless logins and proof of account ownership on Radix for your frontend and backend systems.

The Radix Engine Toolkit is a multi-language library offering Scrypto and Radix Engine types, functions, and primitives for off-ledger applications.

Radix Application Stack

dApp Front-end Development

A pure frontend dApp connects to a user's Radix Wallet, gets data from the Radix Network, and proposes transactions, without a server backend.

Full-stack dApp Development

A full-stack dApp includes a server backend to handle tasks that a pure frontend dApp cannot.

Scrypto

Resources

Resources (tokens/assets) are crucial in Scrypto for safer, predictable transactions. Native to Radix Engine, enforcing correct behaviors.

Authorization

Authorization allows a caller to invoke methods or functions. Scrypto provides a built-in system using Badges, AccessRules, and Roles.

Using Royalties

Radix's native royalty system automatically collects developer-specified fees whenever a blueprint or component is used in a transaction.

Scrypto Test

This testing framework lets developers write Scrypto-like code to test their packages and blueprints.

Design Patterns

Reference Designs

Explore all design patterns including User Badge, Actor Virtual Badge, Transiente Badge, Reusable Blueprints, The Withdraw Pattern, and Patterns for Application use cases.

Reusable Blueprints

Best practice for blueprint developers to ensure reusability and benefit from royalties by publishing to the blueprint catalog (blueprint catalog coming soon).

Users with Badges

This pattern solves how to identify admins or authorized users. Unlike address-based checks, badges ensure secure and composable authorizations.
