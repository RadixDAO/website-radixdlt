The Journey To Hyperscale

~1,000 TPS
2012
Blockchain

Initial research began with scaling.   “Bitcoin” fork to discover realistic upper bound.  Multiple optimizations & improvements implemented.

2013
Block Trees

A “tree of block chains” which allows concurrent transaction processing with delayed reconciliation of state.

~2,000 TPS
2014
DAGs

First “Visa scale” iteration. DAGs allow easy sharding, low messaging overheads, and responsiveness.

~2,500 TPS
2017
CAST

Splitting state & transactional data allowed better management of messaging overheads and security (double spends).

1,400,000 TPS
2020
Tempo

A complete reimagination of state representation & sharding design to minimize overheads of processing & reconciliation.

Unlimited TPS
2020 onwards
Cerberus

Cerberus’ complementary consensus mechanism allows for “cross-shard” communication which preserves all other desirable properties of security & communication overheads.

2022
Olympia
Atomic & Composable

An initial, MVP, un-sharded launch of the Radix network using a hybrid of Hotstuff + Cerberus consensus.

2023 - Present
Babylon
Smart Contracts & 2 Mil Public Test

The currently launched iteration of the network which brought secure, efficient dApps & smart contracts via Scrypto along with an integrated user experience.
